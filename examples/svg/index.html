SVG-графика — jsroll.svg.js

Новый модуль: создание/удаление SVG-примитивов (линия, круг, дуга, многоугольник, путь, текст) и управление их атрибутами через el.svg.attr()/.style()/.animate() — по аналогии с тем, как jsroll.ui.js даёт обычным DOM-узлам .ui/.css. Три примера ниже — три разных способа применения одних и тех же примитивов: постоянно обновляющийся график, круговая диаграмма и «паутинка» (radar chart).

1. Динамический график — circle/polyline + .animate()

Имитация показаний датчика в реальном времени: новая точка каждую секунду, маркеры плавно переезжают на новую высоту.

—
текущее значение
var chart = new SvgCanvas('#line-chart', { viewBox: '0 0 640 220' });
var dot = chart.circle({ cx: x, cy: y0, r: 4, fill: '#0d6efd' });
// … при поступлении новых данных:
dot.svg.animate({ cy: newY }, 500, { easing: svgEasing.easeInOut });
// «Показать среднюю линию» — создание/удаление обычной линии:
var avgLine = chart.line({ x1:0, y1:avgY, x2:640, y2:avgY, stroke:'#dc3545', 'stroke-dasharray':'4 4' });
avgLine.svg.rm(); // удалить
2. Круговая диаграмма — canvas.arc()

Секторы — обычные <path>, построенные помощником Canvas.arc({cx,cy,r,startAngle,endAngle}).

var start = 0;
data.forEach(function (d) {
    var end = start + d.value / total * 360;
    chart.arc({ cx: 110, cy: 110, r: 90, startAngle: start, endAngle: end, fill: d.color });
    start = end;
});
3. Паутинка (radar chart) — canvas.polygon() + canvas.line()

Сетка из концентрических многоугольников, оси — линии из центра, значения — ещё один многоугольник поверх.

// сетка "паутины" — несколько вложенных многоугольников
[0.25, 0.5, 0.75, 1].forEach(function (level) {
    chart.polygon({ points: pointsForLevel(level), fill: 'none', stroke: '#dee2e6' });
});
// оси
axes.forEach(function (a) { chart.line({ x1: cx, y1: cy, x2: a.x, y2: a.y, stroke: '#dee2e6' }); });
// данные — многоугольник поверх сетки, при изменении значений — свой твин точек
dataPolygon.setAttribute('points', pointsForValues(values));
4. Данные, введённые на странице — через пользовательские события

Форма ниже не знает, как устроен график, и не вызывает его функции напрямую — она просто генерирует событие chart.trigger('point:added', {label, value}) на канве. Код, который рисует столбики, ничего не знает про форму — он просто подписан на это событие через chart.on('point:added', ...). Такая развязка позволяет прикрутить к одной и той же канве любой другой источник данных (WebSocket, таймер, другую форму), не трогая код отрисовки. 

    var chart = new SvgCanvas('#user-chart', { viewBox: '0 0 640 240' });

// код отрисовки НЕ знает, откуда берутся данные — только реагирует на событие
chart.on('point:added', function (e) { addBar(e.detail.label, e.detail.value); });
chart.on('point:removed', function () { removeLastBar(); });
chart.on('chart:cleared', function () { clearBars(); });

// обработчик формы НЕ знает, как устроена отрисовка — просто сообщает о новых данных
document.querySelector('#btn-add-point').addEventListener('click', function () {
    chart.trigger('point:added', { label: labelInput.value, value: Number(valueInput.value) });
});
    API модуля вкратце
    • new SvgCanvas(selector, opt) — контейнер <svg>, задаёт viewBox/размеры.
    • canvas.line/circle/ellipse/rect/polyline/polygon/path/text/group(attrs) — создание примитива, атрибуты — как в SVG, но обычным JS-объектом.
    • canvas.arc({cx,cy,r,startAngle,endAngle,...}) — сектор окружности как <path> (для диаграмм).
    • el.svg.attr(name)/.attr(name, value)/.attr({...}) — чтение/запись атрибутов.
    • el.svg.animate({attr: toValue}, duration, {easing, done, step}) — плавный твин числовых атрибутов через requestAnimationFrame.
    • el.svg.addClass/removeClass/hasClass/toggleClass — классы через classList (у SVG-узлов className — не строка).
    • el.svg.rm() / canvas.clear() — удаление одного узла / очистка всей канвы.
    • el.svg.on(type, fn) / .off(type, fn) / .trigger(type, detail) — подписка и генерация как обычных, так и полностью пользовательских событий (у самой канвы — то же самое: canvas.on/off/trigger).
    • svgEasing.linear/easeIn/easeOut/easeInOut — готовые функции плавности для .animate().
    points у polyline/polygon и d у path — строки, а не отдельные числа, поэтому встроенный .animate() их напрямую не анимирует (он тянет только простые числовые атрибуты вроде cx/cy/r/x1…). Для плавного изменения диаграммы (сектора, «паутинка») в примерах ниже — свой небольшой твин по кадрам поверх тех же примитивов, см. tweenPoints()/tweenArc() в коде страницы.
    Пользовательское событие, сгенерированное на фигуре (shape.svg.trigger(...)), всплывает — его поймает и .on(...) на родительской группе, и canvas.on(...) на самой канве (оба — обычные DOM-узлы). У растрового аналога (jsroll.image.js) всплытия у отдельных фигур нет (это не DOM-узлы) — подробности в docs/image.md.
