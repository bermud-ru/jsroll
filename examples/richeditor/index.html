Rich Editor — редактор форматированного текста

Небольшой WYSIWYG-редактор в духе Rich Editor из Filament (панель инструментов + редактируемая область формы), но собранный на jsroll: все элементы панели инструментов и сама область редактирования находятся через ui.el()/ui.els() (а не «голый» document.querySelector — см. пояснение в коде примера про то, почему это важно), а выгрузка в Word сделана штатной функцией библиотеки exportHTML2Word().

Как пользоваться: выделите текст и нажмите Ж / К для жирного/курсивного начертания, «Обычный» — снять форматирование. Кнопки выравнивания применяются к абзацу, в котором стоит курсор. Внизу — выгрузка содержимого в обычный текст (.txt) и в документ Word (.doc, открывается Word'ом благодаря HTML-обёртке с MS-Office namespace).

Как это устроено

Собственно редактирование (жирный/курсив/выравнивание/отмена) выполняет встроенный в браузер document.execCommand() над contenteditable-областью — тот же низкоуровневый API, которым внутри себя уже пользуется сама jsroll (см. jsroll.ui.grid.js, где execCommand('insertBrOnReturn', …) подключается тем же способом). jsroll здесь берёт на себя две вещи: находит элементы через ui.el()/ui.els() (что важно для навешивания .ui.on()-обработчиков, см. код) и делает выгрузку файлов — exportHTML2Word(), bb()/dwnBlob(), storage(). 

// клик по кнопке "Ж" — переключить жирное начертание у выделения
ui.el('#btn-bold').ui.on('mousedown', function (e) {
    e.preventDefault();               // не даём кнопке забрать фокус — иначе выделение в редакторе слетит
    document.execCommand('bold');
    updateToolbarState();
});

// выгрузка в Word — штатная функция jsroll, ничего писать вручную не нужно
ui.el('#btn-export-word').ui.on('click', function () {
    exportHTML2Word(canvas, 'document.doc');
});
