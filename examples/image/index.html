Растровая графика — jsroll.image.js

Тот же функционал, что у jsroll.svg.js — создание/удаление линий, кругов, дуг, многоугольников, управление их свойствами и анимация, — но на <canvas> (растр) вместо <svg> (вектор), с возможностью получить результат как обычный <img>. Те же три примера: живой график, круговая диаграмма, «паутинка».

У canvas, в отличие от SVG, нет отдельного DOM-узла на каждую фигуру — это просто пиксели. Поэтому jsroll.image.js хранит фигуры как обычные JS-объекты (canvas.shapes) и перерисовывает канву целиком при любом изменении — «удаление» фигуры при этом тривиально (убрать из списка). Заодно это даёт приятный побочный эффект: в отличие от SVG-версии этого примера, здесь .raster.animate() одинаково плавно анимирует что угол дуги, что весь массив точек многоугольника — без отдельных ручных твинов на каждый тип фигуры (сравните код секций 2 и 3 здесь и в примере с jsroll.svg.js).
1. Динамический график — circle/polyline + .animate()

Имитация показаний датчика в реальном времени.

—
текущее значение
var chart = new RasterCanvas('#line-chart', { width: 640, height: 220 });
var dot = chart.circle({ cx: x, cy: y0, r: 4, fill: '#0d6efd' });
var poly = chart.polyline({ points: [[x0,y0], [x1,y1], …], stroke: '#0d6efd', 'stroke-width': 2 });
// … при поступлении новых данных — оба твина работают одинаково просто:
dot.raster.animate({ cy: newY }, 700);
poly.raster.animate({ points: newPointsArray }, 700); // animate() сам умеет массивы точек
// "Показать среднюю линию" — создание/удаление обычной линии:
var avgLine = chart.line({ x1:0, y1:avgY, x2:640, y2:avgY, stroke:'#dc3545', dash:[4,4] });
avgLine.raster.rm(); // удалить
2. Круговая диаграмма — canvas.arc()

Секторы — растровые дуги; при изменении значений угол сектора анимируется напрямую, без ручного пересчёта пути по кадрам.

var slice = chart.arc({ cx: 110, cy: 110, r: 90, startAngle: 0, endAngle: 90, fill: '#dc3545' });
// изменение значения — просто анимируем углы, как любое другое число:
slice.raster.animate({ startAngle: newStart, endAngle: newEnd }, 600);
3. Паутинка (radar chart) — canvas.polygon() + canvas.line()

Сетка из концентрических многоугольников, оси — линии из центра, значения — многоугольник поверх.

var dataPolygon = chart.polygon({ points: pointsForValues(values), fill: 'rgba(13,110,253,.25)', stroke: '#0d6efd' });
// изменение любой оси — один вызов, весь многоугольник плавно перестраивается:
dataPolygon.raster.animate({ points: pointsForValues(newValues) }, 500);
4. Снимок канвы как настоящий <img> — canvas.toImage()

Растровые фигуры выше живут на <canvas> (интерактив требует именно его); а вот результат — обычный <img>, который можно вставить куда угодно или скачать как PNG.

Скачать PNG 
var img = pieChart.toImage(document.querySelector('#img-snapshot')); // обновит существующий <img>
downloadLink.href = pieChart.el.toDataURL('image/png');                // тот же PNG — на скачивание
5. Данные, введённые на странице — через пользовательские события

Форма ниже не знает, как устроен график — она просто генерирует chart.trigger('point:added', {label, value}) прямо на канве (canvas.el — настоящий <canvas>, поэтому здесь работает нативный addEventListener/dispatchEvent). chart.on('point:removed', function () { removeLastBar(); });
chart.on('chart:cleared', function () { clearBars(); });

    chart.trigger('point:added', { label: labelInput.value, value: Number(valueInput.value) });

// сохранить картинку и данные в файл — методы самой канвы
chart.download('chart.png');                          // .png — растровый снимок канвы
chart.downloadJSON(pointsData, 'chart-data.json');      // .json — исходные данные, из которых собран график

    Загрузка JSON не вызывает функцию отрисовки напрямую — она просто заново генерирует те же события point:added для каждой точки из файла, ровно как это делает форма выше.

    API модуля вкратце
    • new RasterCanvas(selector, opt) — контейнер <canvas>, opt.width/height — размер в пикселях.
    • canvas.line/circle/ellipse/rect/polyline/polygon/arc/text(attrs) — создание фигуры (обычный JS-объект свойств).
    • shape.raster.attr(name)/.attr(name, value)/.attr({...}) — чтение/запись свойств, каждое изменение перерисовывает канву.
    • shape.raster.animate({свойство: значение, ...}, duration, {easing, done, step}) — плавный твин; работает и с числами, и с массивами точек.
    • shape.raster.rm() / canvas.clear() — удаление одной фигуры / очистка всей канвы.
    • canvas.toImage(imgEl?) — снимок текущего рисунка как <img> (создаёт новый либо обновляет переданный).
    • shape.on(type, fn)/.off(type, fn)/.trigger(type, detail) и то же самое у canvas.on/off/trigger — подписка и генерация пользовательских событий.
    • imageEasing.linear/easeIn/easeOut/easeInOut — готовые функции плавности.
    В отличие от jsroll.svg.js, где события на фигуре всплывают до канвы (это реальные DOM-узлы), здесь у отдельной фигуры (shape.on(...)) всплытия нет — это обычный JS-объект, не элемент DOM. А вот у самой канвы (canvas.on(...)) события — самые настоящие, нативные (canvas.el — реальный <canvas>).
