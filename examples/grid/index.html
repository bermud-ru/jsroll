Электронная таблица — grid()

Демонстрация встроенного модуля jsroll.ui.grid.js: редактируемая таблица с формулами, клавиатурной навигацией и добавлением/удалением строк и столбцов. Ниже — рабочая, стабилизированная версия черновика grid.html: исправлены проблемы исходного прототипа (необработанные клики по кнопкам панели, отсутствие адресации ячеек вида A1, отсутствие пересчёта зависимых формул, потеря нумерации строк/букв столбцов при добавлении/удалении) и добавлены сохранение/экспорт через штатные функции библиотеки.

Как пользоваться: кликните по ячейке — она станет редактируемой. Формулы начинаются с = и используют функцию REF('A1') для ссылки на другую ячейку по адресу «столбец+строка» (например =REF('B2')+REF('B3')). Двойной клик по номеру строки или букве столбца открывает мини-панель добавления/удаления (её же дублируют кнопки на панели инструментов). ↑/↓/←/→ и Enter — навигация по ячейкам, Ctrl+Z — отмена.

Как заданы формулы

Формула — это обычное JS-выражение в атрибуте formula ячейки (так его понимает grid() из jsroll.ui.grid.js), либо то же самое можно ввести прямо в ячейке, начав текст с =. Функция REF('A1') объявлена прямо в этом примере (см. код ниже) — библиотека формул «по буквам столбцов» не содержит, только низкоуровневый доступ table.cell(rowIndex, colIndex, true); REF() транслирует адрес A1 в такой вызов. 

function REF(addr) {
    var m = /^([A-Za-z]+)(\d+)$/.exec(String(addr).trim());
    if (!m) return 0;
    var col = colIndex(m[1].toUpperCase());   // 'A' -> 1, 'B' -> 2, ...
    var row = parseInt(m[2], 10);              // подпись строки совпадает с table.rows-индексом
    var v = table.cell(row, col, true);
    return v === null || v === '' || isNaN(Number(v)) ? 0 : Number(v);
}
Ограничение (как и в большинстве упрощённых реализаций такого рода): REF('A1') ссылается на ячейку по её текущему положению в таблице (индексу строки/столбца), а не «умно» отслеживает адрес при вставке/удалении строк и столбцов. Если удалить или вставить строку/столбец ДО ячейки, на которую ссылается формула, адрес нужно поправить вручную — так же, как это обычно приходится делать при работе с низкоуровневыми механизмами без полноценного движка пересчёта адресов (в отличие от Excel/Google Sheets).
