Запросы — xhr(params)

window.xhr — это функция, принимающая объект настроек (method, url, data, rs — заголовки, before/done/fail/after — колбэки), а не «строитель» с цепочкой .request().process().result(), как всё ещё описывает устаревший docs/xhr.md — в текущем коде такого API нет.

Внутри done/fail/after — this НЕ является объектом XMLHttpRequest (в более ранней версии этого примера и docs/xhr.md утверждалось обратное). xhr() вызывает opt.done(e) обычным вызовом, без .call(x, e) — сам запрос нужно доставать из аргумента: ui.src(e) (или e.target). Исправлено ниже.
Успешный запрос — done
Ошибка — fail и x.responseJSON
Ход выполнения — before / after
