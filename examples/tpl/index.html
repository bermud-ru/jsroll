Шаблонизатор tpl(str, data, cb, opt)

Строка транслируется в JS-функцию один раз (через new Function) и затем многократно вызывается с разными данными. Внутри тегов {% ... %} — обычный JS-код; {%= выражение %} — вывод значения в результат.

Важно: {%= %} выводит значение без экранирования HTML. Если в шаблон попадают данные от пользователя (комментарии, поля форм и т.п.), экранируйте их самостоятельно перед передачей в tpl() — готового «безопасного» тега вывода в библиотеке нет.
1. Простая интерполяция (строка передаётся напрямую)
2. Шаблон по DOM id, с циклом и условием
3. Тот же шаблон, повторный вызов с другими данными (функция уже скомпилирована и переиспользуется)
